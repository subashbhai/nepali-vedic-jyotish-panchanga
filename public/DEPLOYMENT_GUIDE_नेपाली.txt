================================================================================

यो जिप (ZIP) फाइल भित्र तपाईंको वेबसाइट आफ्नै डोमेन (उदा: yourdomain.com) मा सिधै चलाउन 
चाहिने सम्पूर्ण कम्पाइल गरिएका (Production Ready) फाइलहरू समावेश गरिएका छन्।

--------------------------------------------------------------------------------
१. cPanel वा Shared Hosting (Hostinger, Namecheap, Bluehost, GoDaddy, आदि) मा अपलोड गर्ने तरिका:
--------------------------------------------------------------------------------
चरण १: आफ्नो Web Hosting को cPanel वा कन्ट्रोल प्यानलमा Login गर्नुहोस्।
चरण २: "File Manager" खोल्नुहोस् र "public_html" (वा तपाईंको डोमेनको रुट फोल्डर) मा जानुहोस्।
चरण ३: माथि रहेको "Upload" बटनमा क्लिक गरेर यो ZIP फाइल अपलोड गर्नुहोस्।
चरण ४: अपलोड भएपछि उक्त ZIP फाइलमा Right Click गरी "Extract" (Unzip) गर्नुहोस्।
चरण ५: सबै फाइलहरू सिधै "public_html" भित्र हुनुपर्छ (जस्तै: index.html, assets, .htaccess आदि)।
चरण ६: अब आफ्नो ब्राउजरमा डोमेन खोल्नुहोस् (उदा: https://yourdomain.com)। तपाईंको वेबसाइट तत्काल सुरु हुनेछ!

* नोट: यसमा पहिल्यै .htaccess राखिएको छ, जसले गर्दा कुनै पनि पेज रिफ्रेस गर्दा 404 Error आउँदैन।

--------------------------------------------------------------------------------
२. Nginx Web Server (VPS / Cloud Server) प्रयोगकर्ताका लागि:
--------------------------------------------------------------------------------
यदि तपाईं Nginx प्रयोग गर्दै हुनुहुन्छ भने तपाईंको site configuration (server block) मा 
तलको नियम थप्नुहोस्:

server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;
    root /var/www/yourdomain/public_html;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
        expires 1y;
        add_header Cache-Control "public, no-transform";
    }
}

--------------------------------------------------------------------------------
३. Node.js / Express Server मार्फत आफ्नै सर्भरमा चलाउन चाहनुहुन्छ भने:
--------------------------------------------------------------------------------
यस जिप भित्र 'server.cjs' पनि समावेश गरिएको छ।
टर्मिनलमा तलको कमाण्ड चलाउन सक्नुहुन्छ:
   node server.cjs
(यसले पोर्ट 3000 वा PORT वातावरण चरमा वेबसाइट सुरु गर्छ।)
